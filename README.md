# AIO2027-Conquer-Warmup1 — RFM Customer Segmentation
**Group:** Road-to-Papers | **Kaggle Kernel Source:** [https://www.kaggle.com/code/juncuong/warnup](https://www.kaggle.com/code/juncuong/warnup)

This repository implements an end-to-end **RFM Customer Segmentation & Behavioral Analytics Pipeline** on 5 months of eCommerce cosmetics events (10/2019 – 02/2020), refactored into two modular parts:
1. **Part 1 — Setup & Pre-processing (`setup_data.py`)**: Checks for existing `data/processed/pre-processed.csv`. If missing, fetches exclusively from the Kaggle notebook kernel [`juncuong/warnup`](https://www.kaggle.com/code/juncuong/warnup), runs the pre-processing logic, and breaks the data down into small CSV files.
2. **Part 2 — Core RFM Logic & Visualization (`main.py`, `rfm_scoring.py`, `rfm_segmentation.py`, `visualization.py`)**: Computes Recency, Frequency, and Monetary scores (using *Iterative Quantile Peeling* for Frequency), runs **Direction A (11 RFM Segments)** and **Direction B (5 Customer Tiers)**, and displays interactive charts via CLI or **Streamlit**.

## 🚀 Step-by-Step Guide: How to Run the Project

### Prerequisites & Kaggle Credentials

1. Install Python dependencies:
   ```bash
   pip install -r requirements.txt
   # Or using Make:
   make install
   ```
2. Configure your Kaggle credentials in `.env` or `.env.local` (required on the first run when `data/processed/pre-processed.csv` does not exist yet):
   - Edit `.env` (or copy it to `.env.local`) and set your Kaggle credentials:
     ```bash
     export KAGGLE_USERNAME="your_kaggle_username"
     export KAGGLE_KEY="your_kaggle_api_key"
     ```
   - *(Note: `config.py` automatically loads `.env` and `.env.local`, or you can run `source .env` in your terminal).*

---

### Step 1: Run `setup_data.py` (From Kaggle Kernel OR Local `data/raw/` Folder)

Run `setup_data.py` to check for `data/processed/pre-processed.csv`. If missing, you can choose between two data sources to run the pre-processing logic and save the broken-down CSV files into `data/processed/`:

#### Option A: Fetch from Kaggle Kernel (`juncuong/warnup`)
```bash
python3 setup_data.py --from-kernel
# Or via Make:
make setup-from-kernel
```

#### Option B: Process Local Raw CSV Files Placed in `data/raw/`
If you already downloaded the raw CSV files (`2019-Oct.csv`, `2019-Nov.csv`, `2019-Dec.csv`, `2020-Jan.csv`, `2020-Feb.csv`) and placed them into `data/raw/`, run:
```bash
python3 setup_data.py --from-raw
# Or via Make:
make setup-from-raw
```

**CLI Flags for `setup_data.py`:**
- `--from-kernel`: Fetch outputs directly from `https://www.kaggle.com/code/juncuong/warnup`.
- `--from-raw`: Process local CSV files placed inside `data/raw/` (no Kaggle credentials needed).
- `--force`: Force re-run pre-processing and re-generate all CSV files even if `pre-processed.csv` exists.
- `--skip-audit`: Skip the Cell 1 missing-value and duplicate audit step.

---

### Step 2: Save & Track the Pre-processed CSV Files in Git

> **Note:** Skip this step if `data/processed/` already has the pre-processed CSV files tracked in Git. Only execute this step on the initial setup or after re-generating data with `--force`.

The `.gitignore` is configured to **ignore** `data/raw/`, `outputs/`, and `*.parquet` files while **tracking** the small pre-processed CSV files (`data/processed/*.csv`) in Git so your team and Streamlit Cloud can load them immediately.

Run the following commands to stage, commit, and push the pre-processed CSV files:

```bash
# Stage pre-processed CSV files (automatically skips if already tracked in Git)
make track-data

# Or force re-stage after running setup_data.py with --force:
make track-data FORCE=1
# (Equivalent manual command: git add data/processed/*.csv data/processed/purchases_by_month/*.csv)

# Commit and push to your repository
git commit -m "chore(data): add pre-processed RFM CSV files from setup_data.py"
git push origin main
```

## ☁️ Deploying to Streamlit Community Cloud

1. **Run Setup & Track Pre-processed Data**:
   Ensure you have run `python3 setup_data.py --from-kernel` (or `make setup-from-kernel` in Step 1) and committed `data/processed/pre-processed.csv` (Step 2) to GitHub. Because `pre-processed.csv` is ~8 MB (110,518 unique buyers), Streamlit Cloud loads it in `< 2 seconds` well within its 1 GB RAM limit.
2. **Create the Streamlit App**:
   - Go to [share.streamlit.io](https://share.streamlit.io) and sign in with GitHub.
   - Click **New app** → Select your repository `AIO2027-Conquer-Warmup1` and branch `main`.
   - Set **Main file path** to `main.py`.
   - Click **Deploy**.
